# Password Cracker

A simple Python script that demonstrates the concept of brute-force password cracking through random guessing. 

## How it works

The script prompts the user to enter a password and then repeatedly generates random combinations of characters (of the same length) until it finds a match. It visually displays each "guess" in the console, providing a demonstration of how brute-force algorithms operate.

## Usage

To run the script, simply execute it with Python:

```bash
python password_cracker.py
```

Then, follow the prompt to enter a password for the script to "crack".

> [!NOTE]
> This script is a visual demonstration and simulation of random string generation. Since it requires the user to input the target password, it is meant for educational and entertainment purposes rather than practical password recovery.

## Requirements

- Python 3.x
- No external dependencies are required.
